# FastView 1.4.0

FastView 1.4.0 improves large-model viewing and adds professional 3D navigation.

## New

- Added asynchronous full-resolution texture refinement. Models still appear quickly using 512 px textures, then upgrade to their full source resolution in the background, including 8K textures.
- Added an optional viewport statistics overlay with FPS, VRAM usage and budget, polygon count, and vertex count.
- Added native SpaceExplorer and 3Dconnexion SpaceMouse support through Windows Raw Input.
- Added unconstrained six-axis camera flight through scene geometry.
- Added inverted and faster vertical SpaceMouse movement.
- Preview videos now use full-resolution source textures.

## Controls

- Press `F3` to toggle viewport statistics.
- Use **View > SpaceExplorer camera mode** to enable or disable six-axis navigation.
